# playstate

**Now Playing widget for Spotify** — a self-hosted, typed, zero-dependency toolkit to show what you're listening to on your own website.

> 🚧 **Work in progress.** playstate is in its design and foundation phase. Nothing is published on npm yet.

## Packages

| Package | Description |
|---|---|
| `@playstate/core` | Spotify client: token refresh and data normalization |
| `@playstate/server` | Web-standard HTTP handler with caching and CORS |
| `@playstate/cli` | One-command setup to obtain your Spotify refresh token |
| `@playstate/react` | Hook, headless components and a styled card |
