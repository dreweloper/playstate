# @playstate/react

`useNowPlaying` hook, headless components and the styled `NowPlayingCard`. The hook polls the `server` endpoint; the components render the `NowPlaying` model (`ARCHITECTURE.md` section 3.4).

**Runs in:** the browser (React ≥ 18), as a client component.

Folder structure is added in this package's phase (Phase 4).
